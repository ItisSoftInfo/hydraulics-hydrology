# Hydraulics and Hydrology playlists: exercises

Free online exercises for the two playlists Hydraulics and Hydrology on the YouTube channel It is Soft Info: https://www.youtube.com/@ItisSoftInfo

Start here: https://itissoftinfo.github.io/hydraulics-hydrology/

There is nothing to install or download. Change the yellow boxes and the results follow. All units are SI.
