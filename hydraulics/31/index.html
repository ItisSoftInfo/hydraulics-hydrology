Rectangle
Inputs (yellow boxes)
channel width bm
flow Qm³/s
Results
flow per meter width q = Q / bm²/s
q = Q / b
critical depth yc = (q² / g)^(1/3)m
yc = (q² / 9.81)^(1 / 3)
critical velocity Vc = q / ycm/s
Vc = q / yc
check: √(g yc)m/s
check: √ = √(9.81 × yc)
Froude number
Froude number = Vc / check: √
velocity head Vc² / 2g = yc / 2m
Vc² = Vc² / (2 × 9.81)
least specific energy Emin = yc + Vc² / 2gm
Emin = yc + Vc²
check: 1.5 ycm
yc = 1.5 × yc
Trapezoid
Inputs (yellow boxes)
bottom width bm
side slope z (z across : 1 up)
flow Qm³/s
trial depth y (Solve changes it)m
Results
flow area Am²
A = (b + z × y) × y
top width Tm
T = b + 2 × z × y
Q² T / (g A³) (make 1)
Q² T / = Q² × T / (9.81 × A³)
velocity Vm/s
V = Q / A
hydraulic depth D = A / Tm
D = A / T
Froude number
Froude number = V / √(9.81 × D)
specific energy E = y + V² / 2gm
E = y + V² / (2 × 9.81)
1.5 y (the rectangle rule, wrong here)m
y = 1.5 × y
Alternate depth
Inputs (yellow boxes)
flow per meter width qm²/s
given depth y1m
trial other depth y2 (Solve changes it)m
Results
critical depth ycm
yc = (q² / 9.81)^(1 / 3)
E1 = y1 + q² / (2 g y1²)m
E1 = y1 + q² / (2 × 9.81 × y1²)
E2 at the trial depthm
E2 at the trial depth = y2 + q² / (2 × 9.81 × y2²)
difference E2 − E1 (make 0)m
E1 = E2 at the trial depth − E1
Start above yc for the deep depth, below yc for the shallow one.
