Results
jet depth y2 = Cc am
y2 = Cc × a
flow per meter q = y1 y2 √(2g / (y1 + y2))m²/s
q = y1 × y2 × √(2 × 9.81 / (y1 + y2))
flow Q = q bm³/s
Q = q × b
jet velocity V2 = q / y2m/s
V2 = q / y2
Froude number of the jet
jet = V2 / √(9.81 × y2)
Froude number upstream
Froude number upstream = q / y1 / √(9.81 × y1)
discharge coefficient Cd = q / (a √(2 g y1))
Cd = q / (a × √(2 × 9.81 × y1))
check: E upstreamm
check: E upstream = y1 + q² / (2 × 9.81 × y1²)
check: E in the jetm
jet = y2 + q² / (2 × 9.81 × y2²)
depth a jump below the jet needsm
depth a jump below the jet needs = y2 / 2 × (√(1 + 8 × jet²) − 1)
Cc about 0.61 for a sharp-edged opening: US Bureau of Reclamation, Water Measurement Manual (2001).

the gate is
the gate is = if y3 > depth a jump below the jet needs: “drowned”; otherwise “free”
drowned flow Q = Cd a b √(2g (y1 − y3))m³/s
Q = Cd of a submerged orifice × a × b × √(2 × 9.81 × (y1 − y3))
change against free flow
flow = Q / Q − 1
Submerged rectangular orifice, Cd 0.61: US Bureau of Reclamation, Water Measurement Manual (2001).
