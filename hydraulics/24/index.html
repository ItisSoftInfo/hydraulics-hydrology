hydraulic depth = A / b

P = b + 2 × y
hydraulic radius Rm
R = A / P
kinematic viscosity νm²/s
ν = 0.00002414 × 10^(247.8 / (water temperature + 273.15 − 140)) / 1000
Reynolds number V R / ν
Reynolds number = V × R / ν
regime
regime = if Reynolds number < 500: “laminar”; if Reynolds number ≤ 2000: “transitional”; otherwise “turbulent”
