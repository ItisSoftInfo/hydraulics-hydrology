at the edge (control)
edge = yc
area = b × y
R = area / (b + 2 × y)
velocity = Q / area
E = y + velocity² / (2 × 9.81)
Sf = (n × velocity)² / R^(4 / 3)
step 1, upstream
step 1, upstream = (Sf + edge) / 2
step 1, upstream = (E − edge) / (S0 − step 1, upstream)
x = edge + step 1, upstream
step 2, upstream
step 2, upstream = (Sf + step 1, upstream) / 2
step 2, upstream = (E − step 1, upstream) / (S0 − step 2, upstream)
x = step 1, upstream + step 2, upstream
step 3, upstream
step 3, upstream = (Sf + step 2, upstream) / 2
step 3, upstream = (E − step 2, upstream) / (S0 − step 3, upstream)
x = step 2, upstream + step 3, upstream
step 4, upstream

Q by Manning at the trial tailwater − Q (make 0)m³/s

depth where the jump starts (sequent of the tailwater)m
depth where the jump starts = trial tailwater depth / 2 × (√(1 + 8 × (q / trial tailwater depth / √(9.81 × trial tailwater depth))²) − 1)
sectiondepth y (m)area (m²)radius R (m)velocity (m/s)E (m)SfSf barΔx (m)x (m)
at the jet (control)
jet = jet depth
area = b × y
R = area / (b + 2 × y)
velocity = Q / area
E = y + velocity² / (2 × 9.81)
Sf = (n × velocity)² / R^(4 / 3)
step 1, downstream
step 1, downstream = jet depth + 1 × (depth where the jump starts − jet depth) / 4
step 1, downstream = (Sf + jet) / 2
step 1, downstream = (E − jet) / (S0 − step 1, downstream)
x = jet + step 1, downstream
step 2, downstream

x = step 1, downstream + step 2, downstream

x = step 2, downstream + step 3, downstream
step 4, downstream
