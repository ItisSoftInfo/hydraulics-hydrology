Results
aream²
area = π × D² / 4
velocity Vm/s
V = Q / 1000 / area
Reynolds number
Reynolds number = ρ × V × D / μ
friction factor f
f = if Reynolds number < 2300: 64 / Reynolds number; otherwise f if turbulent
head loss hfm
hf = f × L / D × V² / (2 × 9.81)
pressure drop (level pipe)kPa
drop = ρ × 9.81 × hf / 1000
regime
regime = if Reynolds number < 2300: “laminar”; if Reynolds number ≤ 4000: “transitional”; otherwise “turbulent”
laminar check 32 μ L V / D²kPa
laminar check = if Reynolds number < 2300: 32 × μ × L × V / D² / 1000; otherwise “not laminar”
