Manning
Inputs (yellow boxes)
bottom width bm
depth ym
side slope z (z across : 1 up)
Manning n
bed slope S
Results
flow area Am²
A = (b + z × y) × y
wetted perimeter Pm
P = b + 2 × y × √(1 + z²)
hydraulic radius Rm
R = A / P
velocity V = (1/n) R^(2/3) S^(1/2)m/s
V = 1 / n × R^(2 / 3) × √(S)
flow Q = V Am³/s
Q = V × A
Chezy C = R^(1/6) / nm^0.5/s
C = R^(1 / 6) / n
Base n for concrete: 0.012 to 0.018 (USGS Water-Supply Paper 2339, Table 1, public domain).
