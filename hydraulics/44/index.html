Jump
Problem 1: inputs (yellow boxes)
channel width bm
flow Qm³/s
depth before the jump y1m
Results
flow per meter qm²/s
q = Q / b
velocity V1m/s
V1 = q / y1
Froude number Fr1
Fr1 = V1 / √(9.81 × y1)
kind of jump
jump = if Fr1 < 1: “no jump”; if Fr1 < 1.7: “undular”; if Fr1 < 2.5: “weak”; if Fr1 < 4.5: “oscillating”; if Fr1 < 9: “steady”; otherwise “strong”
depth after the jump y2m
y2 = y1 / 2 × (√(1 + 8 × Fr1²) − 1)
E1m
E1 = y1 + q² / (2 × 9.81 × y1²)
E2m
E2 = y2 + q² / (2 × 9.81 × y2²)
head lost ΔE = (y2 − y1)³ / (4 y1 y2)m
ΔE = (y2 − y1)³ / (4 × y1 × y2)
share of E1 lost
lost = ΔE / E1
power lost = γ Q ΔEkW
lost = 9.81 × Q × ΔE
Gate
Problem 2: inputs (yellow boxes)
canal width bm
depth upstream of the gate y0m
gate opening am
contraction coefficient Cc
tailwater depthm
Results
jet depth y1 = Cc am
y1 = Cc × a
flow per meter q (equal energy, upstream and jet)m²/s
q = √(2 × 9.81 × (y0 − y1) / (1 / y1² − 1 / y0²))
flow Qm³/s
Q = q × b
Froude number of the jet
jet = q / y1 / √(9.81 × y1)
sequent depth of the jet y2*m
sequent depth of the jet y2* = y1 / 2 × (√(1 + 8 × jet²) − 1)
where the jump forms
where the jump forms = if tailwater depth < sequent depth of the jet y2* − 0.01: “repelled: further down”; if tailwater depth > sequent depth of the jet y2* + 0.01: “drowned: against the gate”; otherwise “right at the jet”
rise of the tailwater needed to hold it at the jetm
jet = max(0, sequent depth of the jet y2* − tailwater depth)
