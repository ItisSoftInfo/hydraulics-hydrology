wetted perimeter Pm
P = b + 2 × y × √(1 + z²)
hydraulic radius Rm
R = A / P
top width Tm
T = b + 2 × z × y
hydraulic depth = A / Tm
hydraulic depth = A / T
kinematic viscosity νm²/s
ν = 0.00002414 × 10^(247.8 / (water temperature + 273.15 − 140)) / 1000
Reynolds number V R / ν
Reynolds number = V × R / ν
regime
regime = if Reynolds number < 500: “laminar”; if Reynolds number ≤ 2000: “transitional”; otherwise “turbulent”
With R, channel flow is laminar below about 500 and turbulent above about 2,000.
