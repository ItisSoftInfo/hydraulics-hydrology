ν = 0.00002414 × 10^(247.8 / (water temperature + 273.15 − 140)) / 1000
Reynolds number
Reynolds number = V × D / ν
roughness ε in metersm
roughness ε in meters = ε / 1000
relative roughness ε/D
relative roughness = roughness ε in meters / D
start: fully rough f
f = 0.25 / log₁₀(relative roughness / 3.7)²
