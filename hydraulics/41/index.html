Inputs (yellow boxes)
channel width bm
flow Qm³/s
depth before the jump y1m
Results
flow per meter qm²/s
q = Q / b
critical depth ycm
yc = (q² / 9.81)^(1 / 3)
velocity before the jump V1m/s
V1 = q / y1
Froude number Fr1
Fr1 = V1 / √(9.81 × y1)
depth after the jump y2 = y1/2 (√(1 + 8 Fr1²) − 1)m
y2 = y1 / 2 × (√(1 + 8 × Fr1²) − 1)
velocity after the jump V2m/s
V2 = q / y2
Froude number Fr2
Fr2 = V2 / √(9.81 × y2)
specific force before M1 = q²/(g y1) + y1²/2m²
M1 = q² / (9.81 × y1) + y1² / 2
specific force after M2m²
M2 = q² / (9.81 × y2) + y2² / 2
ratio y2 / y1
ratio = y2 / y1
