dynamic viscosity = 0.00002414 × 10^(247.8 / (water temperature + 273.15 − 140))
densitykg/m³
kinematic viscosity νm²/s
ν = dynamic viscosity / density
flow aream²
area = π × pipe diameter² / 4
mean velocitym/s
mean velocity = flow / 1000 / area
Reynolds number
Reynolds number = mean velocity × pipe diameter / ν
regime
regime = if Reynolds number < 2300: “laminar”; if Reynolds number ≤ 4000: “transitional”; otherwise “turbulent”
largest laminar flowL/s
flow = 2300 × ν × π × pipe diameter / 4 × 1000
Viscosity
T (°C)μ (Pa s)ν (m²/s)
μ = 0.00002414 × 10^(247.8 / (T + 273.15 − 140))
ν = μ / 1000
Vogel equation for water; density taken as 1,000 kg/m³ (within 1 % from 0 to 40 °C).
